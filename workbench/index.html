设置

默认不需要 Key：点「生成视频」把需求交给 BigApple 出片。
在 BigApple HTML 预览里打开本页时，直接走 BigApple Agent，全程自动。

高级（可选）：用中转站 Key 在本机后台全自动出片

默认关闭：点「生成」会把开工指令交给 BigApple，你粘贴发送。
勾上下面这个开关后，才在本机后台调用 BigApple 自带的 Claude Code 全自动出片。
Key 只存在本机 ~/.config/mg-workbench/config.json（仅你可读），不会写进网页。不管它就当没有。

已交给 BigApple

开工指令已经复制到剪贴板，BigApple 也已唤起。在 BigApple 里打开这个项目的对话，粘贴并发送就会开始制作。

进度会显示在右上角「任务」里。想全自动出片，可以在「设置」里填中转站 Key。
